This repository contains all projects assigned to me during my internship with codveda technologies(www.codveda.com)

Running Python Scripts:
In your  terminal, run the command: python (filename).py

Running the Django Project
* Install requirements (pip install -r requirements.txt)
* Start the django dev server (python manage.py runserver)
* Create Admin Users:
         python manage.py createsuperuser
         NB: Admin Users cannot regularly be created by the site
*Creating and viewing announcements:
        Only Admin users can create announcements
        The creation of Announcement posts is solely done through the django administration database
